Ajax

Styles for the moments between a click and the server's reply: loading, skeletons and the swap. htmx adds the classes; you add none of the JavaScript.

File: css/utilities/Ajax.css

A region that waits

Choose the button. Until the reply arrives, the skeleton shows in place of the list, so the layout does not jump. No full-page spinner.

The latest orders will appear here.

Code 
<button class="button button--outline" type="button" hx-get="../templates/latest-orders.html" hx-target="#latest-orders" hx-select="unset" hx-swap="innerHTML" hx-push-url="false" hx-indicator="#latest-skeleton" hx-disabled-elt="this">Load the latest orders</button>
<div class="skeleton htmx-indicator" id="latest-skeleton" aria-hidden="true">
    <span class="skeleton__line"></span>
    <span class="skeleton__line skeleton__line--short"></span>
</div>
<div id="latest-orders" aria-live="polite"><p>The latest orders will appear here.</p></div>

Classes

ClassAdded byEffect
.htmx-indicatorYouHidden (opacity 0) until a request runs.
.htmx-requesthtmx, on the element or its hx-indicatorShows the indicator; a button gets the progress cursor.
.htmx-swappinghtmx, on the targetFades the old content out over 150ms.
.skeleton, .skeleton__line, --short, .skeleton__blockYouGrey placeholders that pulse gently.
.ajax-progressYouA thin moving bar, like the one under this site's header.
.ajax-success, .ajax-errorYou or the serverA tinted result message.
.ajax-loader, .is-activeYour own fetch codeThe same indicator, without htmx.

Timing

  • Feedback starts at once: htmx adds .htmx-request before it sends, and the indicator fades in within 200ms.
  • Motion is opacity only, and stops with reduced motion.
  • Give each request its own hx-indicator, so only the region that waits shows it.
