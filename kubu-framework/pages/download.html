Download

Link one stylesheet, or import only the atoms, molecules and organisms a page uses.

Download kubu.min.css Download kubu.css (readable)

The same file is attached to the v2.0.0 release on GitHub: kubu.min.css. With a package manager, run npm install kubu-css or pip install kubu-css.

Option 1: the whole framework

One file with every component, minified, about 60 KB. Copy it into your project and link it.

Code 
<link rel="stylesheet" href="/css/kubu.min.css">

Working from a clone of the repository? Link kubu-framework/styles.css instead. It imports every file in css/, so edits show on reload.

Option 2: only what you use

Every component is its own file. Load the four base files, then the components on the page. A page with one button and one card needs six small files, not the bundle.

Code 
<!-- Base: tokens, spacing and type scales, reset -->
<link rel="stylesheet" href="kubu/css/atoms/colors.css">
<link rel="stylesheet" href="kubu/css/atoms/spacing.css">
<link rel="stylesheet" href="kubu/css/atoms/typography.css">
<link rel="stylesheet" href="kubu/css/atoms/Reset.css">
<!-- Only the components on this page -->
<link rel="stylesheet" href="kubu/css/atoms/Buttons.css">
<link rel="stylesheet" href="kubu/css/organisms/Card.css">

Open the six-file example page. It follows your light or dark setting like the rest of KUBU.

Bundle your own selection

Many link tags mean many requests. Write an entry file of @import lines and let the build script bundle and minify it.

Code 
/* my-kubu.css */
@import url("css/atoms/colors.css");
@import url("css/atoms/spacing.css");
@import url("css/atoms/typography.css");
@import url("css/atoms/Reset.css");
@import url("css/atoms/Buttons.css");
@import url("css/organisms/Card.css");
@import url("css/organisms/Modal.css");
Code 
cd kubu-framework
npm install
node scripts/build.mjs my-kubu.css   # writes dist/my-kubu.css and dist/my-kubu.min.css

Which files a component needs

  • Every page: colors.css, spacing.css, typography.css, Reset.css.
  • Each component page names its file under the title, and Contents lists them all.
  • Two files extend another: organisms/ListGroups.css builds on molecules/ListGroups.css, and organisms/Accordion.css uses the .tab parts in organisms/Tabs.css.
  • Theme radios need utilities/Darkmode.css. Without it the page still follows the system setting.

Build the bundle

The repository builds dist/kubu.css and dist/kubu.min.css from styles.css with Lightning CSS.

Code 
cd kubu-framework
npm install
npm run build      # node scripts/build.mjs
npm run dev        # serve the docs at http://localhost:8080
