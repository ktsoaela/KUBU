Download

Kubu is the hippo. It holds the page: one stylesheet, named parts, and a layout that still works when the script is gone.

One stylesheet

Copy kubu.min.css into the project and link it. kubu.css is the same file, readable. Version 2.0.0.

Download kubu.min.css Download kubu.css

The same file is on the v2.0.0 release.

The link

The link 
<link rel="stylesheet" href="/css/kubu.min.css">

From a package manager

The package name is kubu-css. The pip package holds static files only.

Install 
npm install kubu-css
pip install kubu-css

npm puts the file at node_modules/kubu-css/dist/kubu.min.css. In Django, add kubu_css to INSTALLED_APPS, then {% static 'kubu/kubu.min.css' %}.

Only the parts you use

Each atom, molecule and organism is its own file. Load the four base files, then only the components on the page. A button needs one more file. A card needs another.

The base files and two components 
<link rel="stylesheet" href="kubu/css/atoms/colors.css">
<link rel="stylesheet" href="kubu/css/atoms/spacing.css">
<link rel="stylesheet" href="kubu/css/atoms/typography.css">
<link rel="stylesheet" href="kubu/css/atoms/Reset.css">
<link rel="stylesheet" href="kubu/css/atoms/Buttons.css">
<link rel="stylesheet" href="kubu/css/organisms/Card.css">

Packages you do not need

A component looks right with the stylesheet alone. These folders are optional.

Optional packages
FolderWhat it holds
webA starter site: three pages that link the stylesheet and swap one region.
typographyColours, spacing, type and the reset, without components.
iconsThe icon classes and the SVG sprite.
pluginhtmx patterns: a toast returned with the page, and one listener on a parent.
jsOptional modules for what HTML cannot do alone.
