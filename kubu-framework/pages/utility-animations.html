Animations

Entrance motion in CSS, using only transform and opacity, so it stays smooth and never shifts the layout.

File: css/utilities/Animations.css

Example

Each card runs its animation once when it appears. Reload the page to see it again.

fade-in

Opacity from 0 to 1.

slide-in-left

From the left edge.

slide-in-right

From the right edge.

Code 
<div class="grid grid--auto">
    <article class="card fade-in"><h3 class="card__title">fade-in</h3><p class="card__body">Opacity from 0 to 1.</p></article>
    <article class="card slide-in-left"><h3 class="card__title">slide-in-left</h3><p class="card__body">From the left edge.</p></article>
    <article class="card slide-in-right"><h3 class="card__title">slide-in-right</h3><p class="card__body">From the right edge.</p></article>
</div>

Classes

ClassMotion
.fade-inOpacity, 1 second.
.slide-in-left, .slide-in-rightTransform and opacity, 1 second.

Rules

  • No animation library: CSS keyframes and transitions only.
  • With reduced motion, Reset.css cuts every animation to an instant.
  • Use motion to show where something came from, not to decorate.
