Navs

Links between views of one section, like the pages of an account. Each view is a real URL; the server marks the current one.

File: css/molecules/Navs.css

Default

Profile Security Billing
Code 
<nav class="nav" aria-label="Account">
    <a class="nav__link" href="molecule-navs.html" aria-current="page">Profile</a>
    <a class="nav__link" href="organism-forms.html">Security</a>
    <a class="nav__link" href="organism-tables.html">Billing</a>
</nav>

With htmx

Swap only the panel below the nav. The response for each link includes the nav with the new aria-current, so the highlight moves.

Code 
<section id="account" hx-target="#account" hx-select="#account" hx-swap="outerHTML" hx-push-url="true">
    <nav class="nav nav--tabs" aria-label="Account">
        <a class="nav__link" href="/account" hx-get="/account" aria-current="page">Profile</a>
        <a class="nav__link" href="/account/billing" hx-get="/account/billing">Billing</a>
    </nav>
    …the panel…
</section>

Parts

ClassRole
nav.navBlock: a row of links, with aria-label.
.nav__linkElement: one view, 44px tall. aria-current="page" marks the current one.
.nav--tabs, .nav--pills, .nav--verticalModifier: underline, filled, or stacked.

Navs change the URL. To switch panels on one page without a request, use Tabs.
