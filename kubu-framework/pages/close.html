Close Button in Kubu

The Close Button is a small, interactive element used to dismiss or close components like modals, alerts, notifications, or panels. In the Kubu framework, the close button is designed to be simple, consistent, and easy to use, following the principles of Atomic Design and BEM methodology.

What Is a Close Button?

A close button is typically represented by an "×" symbol and is used to:

  • Close modals or pop-ups.
  • Dismiss alerts or notifications.
  • Collapse panels or sidebars.

It provides users with a clear and intuitive way to exit or hide a component.

Key Features of the Close Button

  1. Simple Design

    The close button is minimalistic, using the "×" symbol to indicate its purpose.

  2. Flexible Positioning

    The button can be positioned anywhere within a component, typically in the top-right corner.

  3. Hover Effects

    The button includes a hover effect to provide visual feedback when interacted with.

  4. Customizable

    The button's appearance can be customized to match your design system.

Example Close Button

Here’s an example of a close button implemented in Kubu:


    <div class="close-button"></div>

Customizing the Close Button

The close button can be customized using CSS variables and modifiers. Here’s the base CSS for the close button:


    /* Base Close Button Styles */
    .close-button {
        display: flex;
        justify-content: flex-end;
        padding: 0.5rem 1rem;
        font-size: var(--font-size-xs);
        color: var(--color-light);
        background: var(--theme);
        cursor: pointer;
    }
    
    .close-button::before {
        content: "\00D7"; /* Unicode for "×" */
        font-size: 1rem;
    }
    
    .close-button:hover {
        background: var(--color-secondary);
    }

You can modify the button's appearance by adjusting the CSS variables or adding new modifiers.

Use Cases for the Close Button

The close button is versatile and can be used in various contexts:

  • Modals: Allow users to close a modal window.
  • Alerts: Let users dismiss notifications or alerts.
  • Panels: Enable users to collapse or hide side panels.
  • Cards: Provide an option to remove or close a card.
