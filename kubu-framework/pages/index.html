Component menu

HTML that styles itself.

KUBU is a CSS framework for server-rendered pages: BEM components, dark and light themes from tokens, and native controls that work with scripts turned off.

Kubu is the hippo. It holds the page: one stylesheet, named parts, and a layout that still works when the script is gone.

Start the intro Download KUBU

Try it with JavaScript off

Everything below is HTML and CSS. Switch the theme in the header: each part follows the tokens in css/atoms/colors.css.

Buttons in every state

Code 
<button class="button button--primary" type="button">Save changes</button>
<button class="button button--outline" type="button">Preview page</button>
<button class="button button--primary" type="button" disabled>Publish page</button>
<button class="button button--primary" type="button" aria-busy="true" aria-disabled="true">Saving</button>
<button class="button button--safe" type="button"><svg class="icon" aria-hidden="true"><use href="../img/icons.svg#check"></use></svg> Saved</button>

Hover and press the first two to see the hover and active states. The third is disabled, the fourth is loading (aria-busy="true"), and the last confirms success with an icon and a word.

    <header class="modal__header">

    </form>
</dialog>

Disclosure

Do I need a build step?

No. Link styles.css or dist/kubu.css and write HTML.

Can I load only the parts I use?

Yes. Each atom, molecule and organism is its own file. Import only what you use.

Code 
<details class="collapse-details" open>
    <summary>Do I need a build step?</summary>
    <p>No. Link <code>styles.css</code> or <code>dist/kubu.css</code> and write HTML.</p>

Form with an inline error

Add the part after the dot, like lindiwe@example.com.

Code 
<form class="form-container form-container--guarded" action="page-contact.html" method="get">
    <div class="form-group">
        <label class="form-label" for="home-email">Email <span class="form-label__hint">(required)</span></label>
        <input class="form-input" id="home-email" name="email" type="email" autocomplete="email" required pattern=".+@.+\..+" value="lindiwe@example" aria-invalid="true" aria-describedby="home-email-error">
        <p class="form-error" id="home-email-error">Add the part after the dot, like lindiwe@example.com.</p>
    </div>
    <div class="form-group">
        <label class="form-label" for="home-topic">Topic</label>
        <select class="form-select" id="home-topic" name="topic">
            <option>Getting started</option>
            <option>Theming</option>
            <option>htmx</option>
        </select>
    </div>
    <button class="button button--primary" type="submit">Send question</button>
</form>

The send button stays dimmed until the email is valid. Fix the address and it wakes up, with no script.
