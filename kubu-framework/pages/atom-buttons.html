Buttons

An action, named by its outcome. Use <button> to do something and <a> to go somewhere; both take .button.

File: css/atoms/Buttons.css

States

Every button is at least 44 by 44 pixels. Hover darkens it, pressing nudges it down, and Tab shows the focus ring.

Code 
<button class="button button--primary" type="button">Save changes</button>
<button class="button button--primary" type="button" disabled>Save changes</button>
<button class="button button--primary" type="button" aria-busy="true" aria-disabled="true">Saving</button>
<button class="button button--safe" type="button"><svg class="icon" aria-hidden="true"><use href="../img/icons.svg#check"></use></svg> Changes saved</button>
<button class="button button--danger" type="button"><svg class="icon" aria-hidden="true"><use href="../img/icons.svg#alert"></use></svg> Try saving again</button>
StateHow to show it
Default, hover, active, focusBuilt in: :hover, :active and :focus-visible.
Disableddisabled on a button; aria-disabled="true" on a link.
Loadingaria-busy="true" draws a spinner after the label. htmx adds .htmx-request for you.
Success, errorThe server returns the button with .button--safe or .button--danger, an icon and new text.

Loading with htmx

Before the response arrives, htmx puts .htmx-request on the button and shows its .htmx-indicator. The server replies with the next state of the button.

Code 
<button class="button button--primary" hx-post="/settings" hx-swap="outerHTML" hx-disabled-elt="this">
    Save changes <span class="spinner spinner--small htmx-indicator" aria-hidden="true"></span>
</button>
<!-- the response -->
<button class="button button--safe" type="button">Changes saved</button>

Sizes, shapes and links

Download Download Sold out
Code 
<a class="button button--primary button--small" href="download.html">Download</a>
<a class="button button--primary button--large" href="download.html">Download</a>
<button class="button button--secondary button--shadow" type="button">Start trial</button>
<a class="button button--outline button--disabled" aria-disabled="true">Sold out</a>

Small buttons keep the 44-pixel height; only the text and side padding shrink. Use .button--large (48 pixels, same type size) for the main action on a phone, low on the screen where a thumb reaches.

Parts

ClassRole
.buttonBlock. Inline flex, so an .icon lines up with the label.
.button--primary, --secondary, --outline, --plain, --dark, --lightModifier: emphasis.
.button--danger, --safe, --hazard, --risk, --info, --radiation, --earthModifier: status tone.
.button--small, --medium, --large, --xlargeModifier: size.
.button--rounded-circle, --shadowModifier: a round icon button, and the card shadow. Every other button takes --kubu-radius.
.button--disabledModifier: the disabled look for a link, with aria-disabled="true".

Microcopy

  • Say the outcome: "Save changes", "Delete invoice", "Copy code". Not "Submit", "OK" or "Click here".
  • An icon goes beside the word. Only a standard close control may be icon-only, and it needs aria-label.
