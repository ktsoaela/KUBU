Buttons in Kubu

Buttons are one of the most essential UI elements in any web application. They allow users to interact with the interface, trigger actions, and navigate through content. In the Kubu framework, buttons are designed to be highly customizable, consistent, and easy to use, following the principles of Atomic Design and BEM methodology.

What Are Buttons?

Buttons are interactive elements that users can click or tap to perform actions. They are commonly used for:

  • Submitting forms.
  • Triggering actions (e.g., saving, deleting).
  • Navigating to other pages or sections.
  • Displaying calls-to-action (e.g., "Sign Up", "Learn More").

Buttons in Kubu are designed to be flexible, with support for different styles, sizes, and states.

Key Features of Buttons

  1. Variants

    Kubu provides a variety of button styles to suit different use cases:

    • Primary: For the main action on a page (e.g., "Submit").
    • Secondary: For secondary actions (e.g., "Cancel").
    • Outline: For less prominent actions with a border and transparent background.
    • Danger: For destructive actions (e.g., "Delete").
    • Info, Success, Warning: For specific status indicators.
  2. Sizes

    Buttons come in different sizes to fit various contexts:

    • Small: Compact buttons for tight spaces.
    • Medium: Standard button size.
    • Large: Prominent buttons for important actions.
    • X-Large: Extra-large buttons for emphasis.
  3. Shapes

    Buttons can be styled with different border radii:

    • Rounded: Slightly rounded corners.
    • Pill-shaped: Fully rounded corners.
    • Circular: Perfectly round buttons (e.g., for icons).
  4. States

    Buttons support different states to provide feedback to users:

    • Hover: Changes appearance when hovered over.
    • Disabled: Indicates that the button is inactive.

Example Buttons

Here are some examples of buttons with different styles and modifiers:


    <button class="button button--primary">Primary</button>
    <button class="button button--secondary">Secondary</button>
    <button class="button button--outline">Outline</button>
    <button class="button button--danger">Danger</button>
    <button class="button button--info">Info</button>
    <button class="button button--success">Success</button>
    <button class="button button--warning">Warning</button>

Customizing Buttons

Buttons in Kubu are highly customizable. You can use modifiers to change their appearance:


    /* Base Button Styles */
    .button {
        display: inline-block;
        padding: var(--space-sm) var(--space-md);
        font-size: var(--font-size-md);
        font-weight: var(--font-weight-bold);
        text-align: center;
        text-decoration: none;
        border-radius: var(--space-xs);
        transition: background-color 0.3s, color 0.3s;
        cursor: pointer;
    }
    
    /* Primary Button */
    .button--primary {
        background-color: var(--button-primary-bg);
        color: var(--button-primary-color);
        border: 1px solid var(--button-primary-bg);
    }
    
    .button--primary:hover {
        background-color: darken(var(--button-primary-bg), 10%);
    }
    
    /* Outline Button */
    .button--outline {
        background-color: transparent;
        color: var(--color-primary);
        border: 1px solid var(--color-primary);
    }
    
    .button--outline:hover {
        background-color: var(--color-primary);
        color: var(--color-light);
    }

You can also create your own modifiers to match your design system.

Button Groups

Button groups allow you to group multiple buttons together for related actions. Here’s an example:


    <div class="button-group">
        <button class="button button--primary">Primary</button>
        <button class="button button--secondary">Secondary</button>
        <button class="button button--outline">Outline</button>
    </div>
