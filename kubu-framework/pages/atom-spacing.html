Spacing

One spacing scale for gaps, padding and margins, so related things sit close and groups stand apart.

File: css/atoms/spacing.css

The scale

  • --space-xs 4px: icon to label
  • --space-sm 8px: buttons in a row
  • --space-md 16px: inside a card, between fields
  • --space-lg 32px: between cards and sections
  • --space-xl 64px: before a new topic
Code 
<ul class="list-unstyled doc-stack">
    <li class="doc-space" style="--size: var(--space-xs)"><code>--space-xs</code> 4px: icon to label</li>
    <li class="doc-space" style="--size: var(--space-sm)"><code>--space-sm</code> 8px: buttons in a row</li>
    <li class="doc-space" style="--size: var(--space-md)"><code>--space-md</code> 16px: inside a card, between fields</li>
    <li class="doc-space" style="--size: var(--space-lg)"><code>--space-lg</code> 32px: between cards and sections</li>
    <li class="doc-space" style="--size: var(--space-xl)"><code>--space-xl</code> 64px: before a new topic</li>
</ul>

In your CSS

Code 
.order-summary {
    display: grid;
    gap: var(--space-md);
    padding: var(--space-lg);
}

Helper classes

For one-off adjustments in markup, the numbered helpers use a second scale, --space-0 to --space-6 (0 to 30px in 5px steps).

ClassSets
.m-*, .mt-*, .mr-*, .mb-*, .ml-*, .mx-*, .my-*Margin, all sides or one side, 0 to 6.
.p-*, .pt-*, .pr-*, .pb-*, .pl-*, .px-*, .py-*Padding, the same way.

Prefer a gap on the parent over margins on each child. The helpers override component spacing, so use them sparingly.
