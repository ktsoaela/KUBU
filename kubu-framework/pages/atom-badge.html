Badge

A short label for a count or a status. The word carries the meaning. Badges share one neutral look; a status badge adds only a tint, never a second accent.

File: css/atoms/Badge.css

Tones

New Paid Overdue Pending 3 updates Archived
Code 
<span class="badge">New</span>
<span class="badge badge--safe">Paid</span>
<span class="badge badge--danger">Overdue</span>
<span class="badge badge--hazard">Pending</span>
<span class="badge badge--info">3 updates</span>
<span class="badge badge--dark">Archived</span>

Next to a heading

Inbox 12 unread

Code 
<h3>Inbox <span class="badge"><span class="badge__label--bold">12</span> <span class="badge__label">unread</span></span></h3>

Parts

ClassRole
.badgeBlock: small, bold, uppercase label on the surface, with the one radius and border.
.badge__label, .badge__label--boldElement: a normal or bold part of the label.
.badge--safe, --danger, --hazard, --risk, --infoModifier: status. A tint of the status colour behind the same text colour.
.badge--light, --darkModifier: a fixed scheme for one badge.

Accessibility

  • Write the status as a word: "Overdue", not a red dot.
  • A count alone is unclear to a screen reader. Add the noun: "12 unread".
