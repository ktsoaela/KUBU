Tables

Tables are a vital part of presenting structured data in a user-friendly format. With Kubu, you can style tables efficiently using CSS classes designed for readability and flexibility. This guide will cover the structure, variations, and best practices for styling tables with Kubu.

CSS Structure

Kubu's table styles rely on a consistent and semantic HTML structure. The main classes include:

  • .table: The base class for table styling.
  • .table__header, .table__footer: Styling for header and footer rows.
  • .table__row: General row styling.
  • .table__cell: Applies to table cells (td or th).
  • .table__row--even: Styling for alternating row colors.

Usage Example

Below is an example of a table styled with Kubu's CSS classes:

# Item Country Qty
1 Yellow Maize Mexico 3
2 Barley Germany 3
3 Coffee Mexico 3
Total 9

Customization

You can further customize tables by:

  • Adding borders with the .table--bordered modifier class.
  • Highlighting rows using .table__row--hover.
  • Aligning text with utility classes like .text-center, .text-left, or .text-right.

For example:

            
                <tr class="table__row table__row--hover">
                    <td class="table__cell text-center">4</td>
                    <td class="table__cell text-left">Rice</td>
                    <td class="table__cell text-right">China</td>
                    <td class="table__cell text-center">10</td>
                </tr>
