Use Cases

KUBU is for HTML that comes from a server or a static file. If your templates already produce the markup, KUBU styles it and the browser makes it interactive.

Server-rendered web apps

Django, Rails, Laravel, Phoenix, Go templates, ASP.NET: anything that renders HTML. Write the BEM classes in your templates. There is no client bundle to keep in sync with the server, and no hydration step.

Invoice 1042

Paid

R 4 300.00, paid on 28 October 2026.

View lines
Code 
<article class="card">
    <div class="card__header"><h3 class="card__title">Invoice 1042</h3><span class="badge badge--safe">Paid</span></div>
    <div class="card__body"><p>R 4 300.00, paid on 28 October 2026.</p></div>
    <div class="card__footer"><a class="button button--outline button--small" href="organism-tables.html">View lines</a></div>
</article>

htmx front ends

htmx swaps HTML fragments returned by the server. KUBU styles the loading state (.htmx-request, .htmx-indicator) and the swap (.htmx-swapping). This site boosts its own links with hx-boost; every page still opens on its own URL without it.

Code 
<button class="button button--primary" hx-post="/orders/1042/ship" hx-target="#status" hx-indicator="this">
    Mark as shipped <span class="spinner spinner--small htmx-indicator"></span>
</button>
<p id="status"></p>

See Ajax and EventDelegation.

Admin tools and dashboards

Tables, forms, tabs, alerts and the grid cover most internal tools. Tabs and accordions are radio groups, so the selected tab can even be submitted with a form.

Content and marketing sites

The snippets, the template and the example pages give a site header, footer, hero, card grid and contact form that work as static files. See Showcases.

When to reach for something else

If your interface is a client-side application with complex shared state, a component framework is the better tool. You can still use KUBU's CSS files for the look: the class names do not depend on how the HTML was produced.
