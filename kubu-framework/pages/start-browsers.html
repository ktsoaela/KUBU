Browser & Devices

KUBU targets the current and previous versions of Chrome, Edge, Firefox and Safari, on desktop and phone.

Native features KUBU relies on

When a feature is missing

  • No commandfor: js/docs.js opens the dialog, or use the :target version on the Modal page.
  • No backdrop-filter: the sticky header and dialog backdrops use a solid colour.
  • No :user-invalid: the browser's own validation message still blocks the send.

How it is tested

npm run smoke (scripts/smoke.mjs) runs the same checks in every browser it finds: htmx swaps and Back, 44-pixel targets, WCAG AA contrast in dark and light, the focus ring, and the dialog, tabs, theme radios and links with scripts off.

  • Chrome, Edge and Firefox are launched directly. The script starts the installed browser headless and drives it itself: Chrome and Edge over the DevTools protocol, Firefox over WebDriver BiDi. A browser that is not installed is skipped with a note.
  • Safari is covered through WebKit. Real Safari cannot be driven on Windows, so the Safari pass runs in WebKit, the engine inside Safari, from Playwright's build. Run npx playwright-core install webkit once to download it.
  • Headless Firefox on Windows never gives its window focus, so its focus-ring check is reported as skipped; Tab moving focus is still checked.
Code 
npm run smoke                        # every browser that is installed
node scripts/smoke.mjs firefox webkit  # only these: chrome, edge, firefox, webkit

The CSS itself is compiled for the browserslist query >= 0.5%, last 2 versions, not dead in scripts/build.mjs.

Devices

  • TouchEvery control is at least 44 by 44 pixels; primary page actions are 48.
  • Narrow screensThe header collapses behind a labelled Menu control, and the component menu follows the article.
  • Zoom and text sizeSizes use rem, so a larger default font scales the whole page.
  • Reduced motionTransitions and animations stop when the system asks for less motion.
