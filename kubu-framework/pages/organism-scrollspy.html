Component menu

Scrollspy

An in-page menu that stays beside long content and marks the section you jumped to. Sticky positioning and :target do it in CSS.

File: css/organisms/Scrollspy.css

Sticky menu with :target

Choose a link: the page jumps to the section and draws a bar beside it.

  • Packing
  • Route
  • Where to stay

Packing

Warm layers: nights in the highlands drop below zero, even in summer.

Route

Maseru to Semonkong takes about three hours by road.

Where to stay

The lodge beside the falls has rooms and camping.

Code 
<div class="scrollspy scrollspy--sticky">
    <nav class="scrollspy-nav" aria-label="On this page">
        <ul class="list-unstyled">
            <li class="scrollspy-nav-item"><a href="#spy-pack">Packing</a></li>
            <li class="scrollspy-nav-item"><a href="#spy-route">Route</a></li>
            <li class="scrollspy-nav-item"><a href="#spy-stay">Where to stay</a></li>
        </ul>
    </nav>
    <div class="scrollspy-content">
        <section class="scrollspy-section" id="spy-pack"><h3>Packing</h3><p>Warm layers: nights in the highlands drop below zero, even in summer.</p></section>
        <section class="scrollspy-section" id="spy-route"><h3>Route</h3><p>Maseru to Semonkong takes about three hours by road.</p></section>
        <section class="scrollspy-section" id="spy-stay"><h3>Where to stay</h3><p>The lodge beside the falls has rooms and camping.</p></section>
    </div>
</div>

Optional: highlight while scrolling

Marking the menu as you scroll, without a click, needs a few lines of JavaScript. It is an enhancement: the menu works without it.

Code 
// Optional. Sets aria-current on the link of the section in view.
const links = document.querySelectorAll('.scrollspy-nav a');
const observer = new IntersectionObserver((entries) => {
    entries.filter((e) => e.isIntersecting).forEach((e) => {
        links.forEach((a) => a.toggleAttribute('aria-current', a.hash === '#' + e.target.id));
    });
}, { rootMargin: '0px 0px -70% 0px' });
document.querySelectorAll('.scrollspy-section').forEach((s) => observer.observe(s));

Parts

ClassRole
.scrollspy, .scrollspy--stickyBlock and modifier: a two-column layout with a sticky menu.
.scrollspy-navThe labelled nav; its list closes properly with </ul>.
.scrollspy-nav-itemOne link. aria-current or .active makes it bold.
.scrollspy-content, .scrollspy-sectionThe content and each section, with an id to jump to.
