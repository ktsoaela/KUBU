typography

A type scale that steps from muted metadata, to body text, to the title, so a page can be scanned before it is read.

File: css/atoms/typography.css

The scale

Title, 52px

Heading 2, 26px

Heading 3, 20px

Body text is 16px with a 1.75 line height, for comfortable reading.

Metadata, 12px and muted: updated 31 October 2026

Code 
<p class="title">Title, 52px</p>
<h2>Heading 2, 26px</h2>
<h3>Heading 3, 20px</h3>
<p>Body text is 16px with a 1.75 line height, for comfortable reading.</p>
<p><small>Metadata, 12px and muted: updated 31 October 2026</small></p>

Tokens

TokenValueUse
--font-size-xs0.75remBadges, metadata
--font-size-sm0.875remSecondary text, tables
--font-size-md1remBody
--font-size-lg1.25remLead text, h3
--font-size-xl1.625remh2
--font-size-xxl2.25remh1
--font-size-xxxl3.25rem.title

Families: --font-family-sans (Raleway), --font-family-serif (Lora) and --font-family-mono. Weights and line heights have tokens too.

Rules

  • One h1 per page, then headings in order.
  • One focal headline, one supporting sentence, then the content.
