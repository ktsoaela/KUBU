Colors

The semantic tokens every component reads. Override them to make a theme; switch the header to Dark or Light to see both values.

File: css/atoms/colors.css

Surfaces and text

  • --kubu-bg Page background
  • --kubu-surface Cards, dialogs, fields
  • --kubu-surface-2 Hover rows, stripes
  • --kubu-border Lines and outlines
  • --kubu-text Body text
  • --kubu-text-muted Metadata
  • --kubu-heading Headings
Code 
<ul class="grid grid--auto list-unstyled">
    <li class="doc-swatch" style="--swatch: var(--kubu-bg)"><code>--kubu-bg</code> Page background</li>
    <li class="doc-swatch" style="--swatch: var(--kubu-surface)"><code>--kubu-surface</code> Cards, dialogs, fields</li>
    <li class="doc-swatch" style="--swatch: var(--kubu-surface-2)"><code>--kubu-surface-2</code> Hover rows, stripes</li>

    <li class="doc-swatch" style="--swatch: var(--kubu-text)"><code>--kubu-text</code> Body text</li>

Actions and focus

Brand colour is for actions and links only.

  • --kubu-primary Primary buttons, current item
  • --kubu-primary-hover Hover
  • --kubu-link Links, outline buttons
  • --kubu-focus Focus ring
  • --theme-color-secondary Secondary buttons, announcements
Code 
<ul class="grid grid--auto list-unstyled">
    <li class="doc-swatch" style="--swatch: var(--kubu-primary)"><code>--kubu-primary</code> Primary buttons, current item</li>
    <li class="doc-swatch" style="--swatch: var(--kubu-primary-hover)"><code>--kubu-primary-hover</code> Hover</li>
    <li class="doc-swatch" style="--swatch: var(--kubu-link)"><code>--kubu-link</code> Links, outline buttons</li>
    <li class="doc-swatch" style="--swatch: var(--kubu-focus)"><code>--kubu-focus</code> Focus ring</li>
    <li class="doc-swatch" style="--swatch: var(--theme-color-secondary)"><code>--theme-color-secondary</code> Secondary buttons, announcements</li>
</ul>

Status

These keep their meaning in both schemes. Components pair them with an icon and text.

  • --color-danger Errors, destructive actions
  • --color-hazard Warnings
  • --color-safe Success
  • --color-info Information

Other tokens

TokenUse
--dark-*, --light-*The two values behind each --kubu-* token. Dark is authored first.
--kubu-on-primaryText on the primary colour.
--kubu-overlaySolid backdrop behind dialogs and panels.
--kubu-shadow-sm, -md, -lgSoft shadows, used sparingly.
--kubu-targetThe smallest touch target: 44px.
