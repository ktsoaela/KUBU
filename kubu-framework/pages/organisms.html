Organisms of Kubu

Organisms are more complex components made up of multiple molecules and atoms. They represent standalone sections of the UI, such as modals, carousels, and form structures, ensuring modular and scalable design.

How BEM and Atomic Design Work Together

Organisms in Kubu follow the BEM methodology to create structured, reusable, and maintainable components. Each organism consists of multiple molecules and atoms, ensuring consistency and scalability across projects.

Organisms Overview

Below is a breakdown of the organisms used in Kubu:

Accordion

Accordions allow content to be expanded or collapsed in a structured manner, useful for FAQs and collapsible sections.

Alerts

Alert components display important messages, warnings, or notifications to users, often with dismiss functionality.

Card

Cards are flexible content containers used to display information, including images, text, and actions.

Carousel

Carousels allow users to browse through multiple content items, such as images or testimonials, with navigation controls.

Collapse

The collapse component toggles visibility for content areas, commonly used for menus and dynamic sections.

Date Picker

A date picker provides a calendar interface for selecting dates, improving user experience in form inputs.

File Upload

The file upload component allows users to attach files using drag-and-drop or traditional file selection.

Forms

Forms combine multiple form elements into structured input sections, including validation and labels.

List Groups

List groups display structured lists with optional interactive features like selection and actions.

Modal

Modals create overlays with dialogs or interactive content that requires user attention.

Offcanvas

The offcanvas component provides slide-in panels for navigation or additional content.

Popovers

Popovers display contextual content when users hover or click on elements, often used for tooltips or additional information.

Progress

Progress bars visually represent the completion status of tasks or processes.

Scrollspy

Scrollspy automatically updates navigation elements based on scroll position within a page.

Stepper

Steppers help users navigate through multi-step processes, providing a clear progression indicator.

Tables

Tables display structured data in rows and columns, supporting sorting and filtering.

Tabs

Tabs organize content into separate sections, allowing users to switch between views dynamically.

Toasts

Toasts are small notifications that appear temporarily to provide feedback or updates.

Tooltips

Tooltips display additional information when users hover over elements, enhancing UX clarity.

Rating

The rating component allows users to provide feedback using stars or other rating symbols.
