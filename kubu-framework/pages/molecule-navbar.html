Component menu

Navbar

A labelled row of links: the logo first, the menu after it. The full site header that wraps it is the Navbar snippet.

File: css/molecules/Navbar.css

Example

Basotho Crafts
  • Home
  • Products
  • About
  • Contact
Code 
<nav class="navbar" aria-label="Shop">
    <a class="navbar-brand" href="page-home.html">Basotho Crafts</a>
    <ul class="navbar-nav">
        <li class="nav-item"><a class="nav-link" href="page-home.html" aria-current="page">Home</a></li>
        <li class="nav-item"><a class="nav-link" href="page-product.html">Products</a></li>
        <li class="nav-item"><a class="nav-link" href="page-about.html">About</a></li>
        <li class="nav-item"><a class="nav-link" href="page-contact.html">Contact</a></li>
    </ul>
</nav>

With a dropdown

Basotho Crafts
  • Products
  • Account menu
    • Profile
    • Orders
Code 
<nav class="navbar" aria-label="Account">
    <a class="navbar-brand" href="page-home.html">Basotho Crafts</a>
    <ul class="navbar-nav">
        <li class="nav-item"><a class="nav-link" href="page-product.html">Products</a></li>
        <li class="nav-item">
            <details class="dropdown dropdown--end">
                <summary class="nav-link">Account menu</summary>
                <ul class="dropdown-content">
                    <li><a class="dropdown-item" href="page-about.html">Profile</a></li>
                    <li><a class="dropdown-item" href="page-contact.html">Orders</a></li>
                </ul>
            </details>
        </li>
    </ul>
</nav>

Parts

ClassRole
nav.navbarBlock: the bar, with aria-label.
.navbar-brandThe logo or site name, linking home.
ul.navbar-nav > li.nav-item > a.nav-linkThe menu. Mark the current page with aria-current="page".

Rules

  • Every link is a word. Seven links is plenty; group the rest in a dropdown.
  • On a narrow screen, collapse the links behind a control labelled "Menu". See the snippet.
