Timeline

What happened, in order. It is an ordered list: the line is the one border, and each date is text, so the order reads the same without the line.

File: css/organisms/Timeline.css

An order's history

  1. 28 October, 09:12

    Order placed

    Two Seanamarena blankets, paid by M-Pesa.

  2. 29 October, 15:40

    Shipped from Maseru

    Courier reference LS-88213.

  3. 31 October, 11:05

    Now: at the Mafeteng depot

    Out for delivery on the next working day.

Code 
<ol class="timeline" aria-label="Order KB-1042">
    <li class="timeline__item">
        <time class="timeline__date" datetime="2026-10-28T09:12">28 October, 09:12</time>
        <p class="timeline__title">Order placed</p>
        <p class="timeline__text">Two Seanamarena blankets, paid by M-Pesa.</p>
    </li>
    <li class="timeline__item">
        <time class="timeline__date" datetime="2026-10-29T15:40">29 October, 15:40</time>
        <p class="timeline__title">Shipped from Maseru</p>
        <p class="timeline__text">Courier reference LS-88213.</p>
    </li>
    <li class="timeline__item" aria-current="step">
        <time class="timeline__date" datetime="2026-10-31T11:05">31 October, 11:05</time>
        <p class="timeline__title">Now: at the Mafeteng depot</p>
        <p class="timeline__text">Out for delivery on the next working day.</p>
    </li>
</ol>

Parts

ClassRole
.timelineBlock: an <ol> with the one border down its side.
.timeline__itemElement: one step, with a marker on the line.
.timeline__dateElement: a <time> with a datetime the server prints.
.timeline__title, .timeline__textElement: what happened, and a line about it.
[aria-current="step"]State: the latest step. Its marker is filled, and its title says "Now".

Accessibility

  • Use <ol>, so a screen reader says how many steps there are.
  • Write each date as text. The marker and the line are decoration.
  • Name the list with aria-label when the page has more than one.
