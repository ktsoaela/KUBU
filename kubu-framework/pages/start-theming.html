Theming and dark mode

A theme is an override of the tokens in css/atoms/colors.css. Components read only those tokens, so every part follows.

Dark is the master theme

Each colour is written for dark first (--dark-*), then paired with a light value (--light-*). light-dark() picks one from the page's colour scheme.

Code 
:root {
    color-scheme: light dark;              /* follow the system */
    --dark-primary: #2a77b5;
    --light-primary: #002d4c;
    --kubu-primary: light-dark(var(--light-primary), var(--dark-primary));
}
[data-theme="dark"]  { color-scheme: dark; }
[data-theme="light"] { color-scheme: light; }

Choosing a scheme

  • Do nothingWith no saved choice the page follows the visitor's system setting. KUBU never forces dark on a light system.
  • Set it on the serverRender <html data-theme="dark"> or "light" from a saved preference.
  • Let the visitor pickThree radio buttons with the ids below. utilities/Darkmode.css reads them with :has(), so they work with scripts off.
Colour theme
Code 
<fieldset class="theme-switch-list">
    <legend class="visually-hidden">Colour theme</legend>
    <input type="radio" name="demo-theme" id="demo-auto" value="auto" checked><label for="demo-auto">Auto</label>
    <input type="radio" name="demo-theme" id="demo-dark" value="dark"><label for="demo-dark">Dark</label>
    <input type="radio" name="demo-theme" id="demo-light" value="light"><label for="demo-light">Light</label>
</fieldset>

This demo uses its own ids, so it does not change the page. On a real page use the ids auto-mode, dark-mode and light-mode, like the switch in this site's header. To remember the choice, save it in localStorage and set data-theme before the page paints; this site does it in one line in the <head>.

Make your own theme

Override the tokens on :root for the whole site, or on any element for one section. Keep the brand colour for actions and links.

Earth theme

The card did not change. Only four tokens did.

See all tokens Card parts
Code 
<article class="card theme-earth">
    <h3 class="card__title">Earth theme</h3>
    <div class="card__body"><p>The card did not change. Only four tokens did.</p></div>
    <footer class="card__footer">
        <a class="button button--primary" href="atom-colors.html">See all tokens</a>
        <a class="button button--outline" href="organism-card.html">Card parts</a>
    </footer>
</article>
Code 
.theme-earth {
    --kubu-primary: light-dark(#7a3e10, #b0652a);
    --kubu-primary-hover: light-dark(#5e2f0b, #8e4f1f);
    --kubu-link: light-dark(#7a3e10, #f0b46c);
    --kubu-heading: light-dark(#7a3e10, #f0b46c);
}

Rules for a theme

  • Text and the focus ring must meet WCAG AA in both schemes: 4.5:1 for text, 3:1 for the ring.
  • Danger, hazard, safe and info keep their meaning. Change their shade, not their hue.
  • Check each change with the switch in the header set to Dark, then Light.
