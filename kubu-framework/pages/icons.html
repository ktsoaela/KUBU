Icon Pack

Line icons in one SVG sprite, img/icons.svg. They are drawn with currentColor, so they take the colour of the text around them and follow the theme. No icon font, no script.

Usage

Load css/atoms/Icons.css (included in styles.css) and point <use> at a symbol in the sprite.

Download
Code 
<svg class="icon" aria-hidden="true"><use href="../img/icons.svg#home"></use></svg>
<a class="button button--primary" href="download.html"><svg class="icon" aria-hidden="true"><use href="../img/icons.svg#download"></use></svg> Download</a>
<button class="button button--outline" type="button"><svg class="icon" aria-hidden="true"><use href="../img/icons.svg#search"></use></svg> Search the docs</button>
<button class="modal__close" type="button" aria-label="Close"><svg class="icon" aria-hidden="true"><use href="../img/icons.svg#close"></use></svg></button>

Browsers load an external sprite only over HTTP from the same origin, so open the site through a local server (npm run dev), not from file://. To avoid the request, paste the <symbol> elements into a hidden <svg> at the top of your page and use href="#home".

Accessibility

  • Icons next to text are decoration: keep aria-hidden="true".
  • An icon-only button needs an aria-label that says what it does.
