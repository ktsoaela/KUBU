Avatar

A photo or initials for a person or a shop. It has the one radius and the one border, like a card. A presence dot only sits beside a word, so the state is never only a colour.

File: css/atoms/Avatar.css

Photo and initials

LM TR
Code 
<img class="avatar avatar--sm" src="../img/hippo-black.svg" alt="KUBU blanket shop" width="32" height="32">
<span class="avatar" role="img" aria-label="Lerato Mokoena">LM</span>
<span class="avatar avatar--lg" role="img" aria-label="Thabo Ramakatane">TR</span>

With a name and presence

  • LM Lerato Mokoena In the shop
  • TR Thabo Ramakatane At the loom
Code 
<ul class="list-unstyled">
    <li class="avatar-label">
        <span class="avatar" aria-hidden="true">LM</span>
        <span>Lerato Mokoena <span class="presence presence--on"><span class="presence__dot" aria-hidden="true"></span>In the shop</span></span>
    </li>
    <li class="avatar-label">
        <span class="avatar" aria-hidden="true">TR</span>
        <span>Thabo Ramakatane <span class="presence presence--away"><span class="presence__dot" aria-hidden="true"></span>At the loom</span></span>
    </li>
</ul>

Parts

ClassRole
.avatarBlock: an img, or a span of initials, 40px square with the one radius.
.avatar--sm, --lgModifier: 32px or 64px. Or set --avatar-size.
.avatar-labelBlock: an avatar and a name side by side.
.presence, .presence__dotBlock and element: a word such as "In the shop", with a dot before it.
.presence--on, --awayModifier: the dot's tone. The word still says the state.

Accessibility

  • A photo needs alt with the person's name. Initials alone need role="img" and an aria-label.
  • When the name is written next to the avatar, hide the avatar with aria-hidden="true" so the name is not read twice.
  • Never show presence as a dot alone. Write the word.
