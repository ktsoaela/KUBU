Spacing in Kubu

Spacing is a critical aspect of web design, ensuring that elements are properly aligned and visually balanced. In the Kubu framework, spacing is defined using a consistent set of CSS variables and utility classes, making it easy to apply and maintain across your project.

What Is Spacing in Kubu?

Spacing in Kubu refers to the system of margins, padding, and gaps used to create space between elements. This system is designed to:

  • Ensure consistent spacing across your application.
  • Make it easy to align and position elements.
  • Provide a scalable and maintainable way to manage spacing.

All spacing values are defined as CSS variables, making them easy to use and customize.

Key Spacing Variables

Kubu provides a set of spacing variables that can be used for margins, padding, and gaps. Here’s a breakdown of the key variables:

  1. Base Spacing Variables

    These variables define the core spacing values used throughout the framework:

    
    --space-ss: 2px;
    --space-xs: 4px;
    --space-sm: 8px;
    --space-md: 16px;
    --space-lg: 32px;
    --space-xl: 64px;
    --space-xxl: 96px;
    --space-ss (2px)
    --space-xs (4px)
    --space-sm (8px)
    --space-md (16px)
    --space-lg (32px)
    --space-xl (64px)
    --space-xxl (96px)
  2. Incremental Spacing Variables

    These variables provide a more granular set of spacing values:

    
    --space-0: 0px;
    --space-1: 5px;
    --space-2: 10px;
    --space-3: 15px;
    --space-4: 20px;
    --space-5: 25px;
    --space-6: 30px;
    --space-0 (0px)
    --space-1 (5px)
    --space-2 (10px)
    --space-3 (15px)
    --space-4 (20px)
    --space-5 (25px)
    --space-6 (30px)

Spacing Utilities

Kubu provides utility classes for applying spacing to elements. These classes are based on the spacing variables and can be used for margins, padding, and gaps.

  1. Margin Utilities

    These classes apply margins to elements:

    
    .m-0 { margin: var(--space-0) !important; }
    .m-1 { margin: var(--space-1) !important; }
    .m-2 { margin: var(--space-2) !important; }
    .m-3 { margin: var(--space-3) !important; }
    .m-4 { margin: var(--space-4) !important; }
    .m-5 { margin: var(--space-5) !important; }
    .m-6 { margin: var(--space-6) !important; }
    .m-1 (5px margin)
    .m-2 (10px margin)
    .m-3 (15px margin)
  2. Padding Utilities

    These classes apply padding to elements:

    
    .p-0 { padding: var(--space-0) !important; }
    .p-1 { padding: var(--space-1) !important; }
    .p-2 { padding: var(--space-2) !important; }
    .p-3 { padding: var(--space-3) !important; }
    .p-4 { padding: var(--space-4) !important; }
    .p-5 { padding: var(--space-5) !important; }
    .p-6 { padding: var(--space-6) !important; }
    .p-1 (5px padding)
    .p-2 (10px padding)
    .p-3 (15px padding)
  3. Directional Utilities

    These classes apply spacing to specific sides of an element:

    
    .mt-1 { margin-top: var(--space-1) !important; }
    .mr-1 { margin-right: var(--space-1) !important; }
    .mb-1 { margin-bottom: var(--space-1) !important; }
    .ml-1 { margin-left: var(--space-1) !important; }
    
    .pt-1 { padding-top: var(--space-1) !important; }
    .pr-1 { padding-right: var(--space-1) !important; }
    .pb-1 { padding-bottom: var(--space-1) !important; }
    .pl-1 { padding-left: var(--space-1) !important; }
    .mt-1 (5px top margin)
    .pl-2 (10px left padding)

Using Spacing in Kubu

To use the spacing variables or utility classes in your project, simply reference them in your CSS or HTML:


    /* Example: Applying spacing variables */
    .container {
        padding: var(--space-md);
        margin-bottom: var(--space-lg);
    }
    
    /* Example: Using utility classes */
    <div class="m-2 p-3">Content</div>

You can also override these variables to create custom spacing scales or adapt them to your design system.

Next Steps

Now that you understand the spacing system in Kubu, you can start using these variables and utilities to create well-structured and visually balanced layouts. Explore the documentation for more examples and advanced usage.
