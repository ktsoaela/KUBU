Colors in Kubu

Colors are a fundamental part of any design system. In the Kubu framework, colors are defined using CSS variables, making them easy to use, customize, and maintain. The color system is designed to be consistent, flexible, and aligned with the principles of Atomic Design and BEM methodology.

What Are Colors in Kubu?

Kubu provides a comprehensive color system that includes:

  • Primary and Secondary Colors: For branding and key UI elements.
  • Background Colors: For page and component backgrounds.
  • Highlight Colors: For drawing attention to specific elements.
  • Neutral Colors: For text, borders, and subtle UI elements.
  • Status Colors: For indicating states like danger, success, or warning.
  • Theme Colors: For consistent theming across the application.

All colors are defined as CSS variables, making it easy to apply and modify them throughout your project.

Using Colors in Kubu

To use the color variables in your project, simply reference them in your CSS or HTML:


    /* Example: Applying a color variable */
    .button {
        background-color: var(--color-primary);
        color: var(--color-light);
    }

You can also override these variables to create custom themes or adapt the colors to your brand.
