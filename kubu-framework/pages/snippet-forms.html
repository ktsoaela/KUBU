Forms

Base styles for bare form elements, so a form from a server template looks right before it has a single class.

File: css/snippets/Forms.css. For classes, errors and validation, see the Forms organism.

A form with no classes

Code 
<form action="snippet-forms.html" method="get">
    <label for="sf-town">Town</label>
    <input id="sf-town" name="town" type="text" autocomplete="address-level2" placeholder="e.g. Mafeteng">
    <label for="sf-date">Pick-up date</label>
    <input id="sf-date" name="date" type="date">
    <label for="sf-size">Parcel size</label>
    <select id="sf-size" name="size">
        <option>Small, up to 2 kg</option>
        <option>Large, up to 10 kg</option>
    </select>
    <button type="submit">Book a pick-up</button>
</form>

Checkboxes and radios

Put the input inside its label. The whole row is the 44px target, and the input stays in the page and in the tab order. A checked box draws a tick, a checked radio draws a dot, so the state is never only a colour.

Code 
<form action="snippet-forms.html" method="get">
    <label><input type="checkbox" name="gift" checked> Wrap it as a gift</label>
    <label><input type="checkbox" name="receipt"> Email me the receipt</label>
    <label><input type="checkbox" name="insure" disabled> Insure the parcel (not for this size)</label>
</form>

Fieldset and legend

Group a set of radios, or any related fields, in a <fieldset>. The <legend> is the question, and a screen reader reads it before each choice.

Delivery
Code 
<form action="snippet-forms.html" method="get">
    <fieldset>
        <legend>Delivery</legend>
        <label><input type="radio" name="delivery" value="collect" checked> Collect from the shop in Maseru</label>
        <label><input type="radio" name="delivery" value="courier"> Courier to my door, M60</label>
        <label><input type="radio" name="delivery" value="post"> Post office, M25</label>
    </fieldset>
</form>

Range and output

The row is 44px tall, so the thumb is easy to grab. The number is written in an <output> next to the slider, so the value is read as text and not guessed from the thumb. The server prints the first value. One hx-on:input keeps it in step. With scripts off, the number shows the value the page was printed with.

M800
Code 
<form action="snippet-forms.html" method="get" hx-on:input="this.budget_out.value = 'M' + this.budget.value">
    <label for="budget">Most you will spend on a blanket</label>
    <input type="range" id="budget" name="budget" min="200" max="2000" step="50" value="800">
    <output id="budget_out" for="budget">M800</output>
</form>

What it styles

SelectorStyle
Text-like inputs, textarea, selectFull width, a token border, 44px tall.
labelBold, on its own line.
[type="checkbox"], [type="radio"]A token border, a tick, dash or dot when on. A label around one is a 44px row. Zero specificity, so tabs and rating still hide their radios.
fieldset, legendThe one border and radius around a group. The legend is bold body text.
[type="range"], outputA 44px row with a thin track and a round thumb. The output is bold, with figures that do not jump.
button, [type="submit"], [type="reset"]The primary colour, 44px tall. A .button class overrides it.
.error-messagePlain error text. Prefer .form-error, which adds the icon.

Leave this file out if your site styles every control with classes.
