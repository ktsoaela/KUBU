News

A release number is MAJOR.MINOR.PATCH. The highest number replaces the one below it. 2.0.0 is the release you install.

2.0.0

31 October 2026

Current

Major 2, because the public API changed. Minor 0 and patch 0, because this is the first release of that API. A fix on this API is 2.0.1. A new part that keeps this API working is 2.1.0. A break of this API is 3.0.0.

  • One stylesheet, kubu.min.css, for the whole page.
  • Named parts: a card is a header, a body, and a footer.
  • The layout still works when the script is gone. htmx only swaps a region.
  • Dark is the master theme. Light is the pair, through light-dark().
  • A 12-column grid, and a 13-column grid when you need 5 and 8.
  • Packages for a starter site, icons, and type. The same CSS file in each.

The release branch is prod. stable is the default branch on GitHub and the same 2.0.0, stopped on 31 October 2026 when dist/kubu.css was last rebuilt. Install it with npm install kubu-css or pip install kubu-css. The same file is in the web, icons, typography, plugin, and js packages.

Read the 2.0.0 contract. Download the stylesheet.

1.0.0

3 February 2025

Previous major

The previous public API. 2.0.0 replaced it. The branch is 1-css-components.

  • Separate CSS files, named with BEM.
  • Page colour was written as hex on the page.
  • A Vue site, kubu-web, showed the components. kubu.20 held the optional script layer.
  • The public API changed in 2.0.0: HTML pages and light-dark() tokens.

0.y.z

Initial development

Before 1.0.0 the public API could change at any time. These branches carry that work. They have no release number of their own.

  • main, 22 March 2024. The first copy. One folder, kubu_ui, and a 13-column grid.
  • staging, 13 June 2024. A backend and a frontend, written while the components moved to plain JavaScript.
  • presentation, 20 June 2024. Buttons, breadcrumbs, and type, and a start on the documentation.
  • bugfix, 7 November 2024. One round of fixes. The folders are kubu-css and kubu-web.
  • experimental, 5 February 2025. Files added by hand, in kubu-css and kubu-framework. That commit stayed unreleased, so it did not become 1.0.1 or 1.1.0.
