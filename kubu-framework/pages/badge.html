Badges in Kubu

Badges are small, versatile UI elements used to highlight important information, such as notifications, labels, or status indicators. In the Kubu framework, badges are designed to be lightweight, customizable, and consistent with the principles of Atomic Design and BEM methodology.

What Are Badges?

Badges are compact components that provide visual cues to users. They are often used to:

  • Display notifications (e.g., unread messages).
  • Label items (e.g., "New", "VIP", "Sale").
  • Indicate status (e.g., "Active", "Pending", "Completed").

Badges are typically small, rounded, and use contrasting colors to stand out. They can contain text, icons, or both.

Key Features of Badges

  1. Content

    Badges can include:

    • Text: Short, descriptive labels like "New" or "Hot".
    • Icons: Visual indicators like a bell for notifications or a star for favorites.
  2. Styling

    Badges are styled to be visually distinct:

    • Colors: Use background colors to convey meaning (e.g., red for errors, green for success).
    • Shape: Typically rounded or pill-shaped for a soft, modern look.
    • Text: Contrasting text color ensures readability.
  3. Size and Padding

    Badges are designed to be compact yet balanced:

    • Padding ensures content doesn’t feel cramped.
    • Font size is small to maintain a lightweight appearance.
  4. Positioning

    Badges are often positioned relative to other elements, such as:

    • In the corner of a button or icon.
    • Inline with text or labels.

Customizing Badges

Badges in Kubu are highly customizable. You can use modifiers to change their appearance:


    /* Base Badge Styles */
    .badge {
        display: inline-block;
        padding: var(--space-xs) var(--space-sm);
        border-radius: var(--space-xs);
        font-size: var(--font-size-xs);
        font-weight: var(--font-weight-bold);
        text-transform: uppercase;
    }
    
    /* Modifiers for Different Badge Types */
    .badge--primary {
        color: var(--color-light);
        background-color: var(--color-primary);
    }
    
    .badge--secondary {
        color: var(--color-light);
        background-color: var(--color-secondary);
    }
    
    .badge--danger {
        color: var(--color-light);
        background-color: var(--color-danger);
    }
    
    .badge--info {
        color: var(--color-light);
        background-color: var(--color-info);
    }

You can also create your own modifiers to match your design system.

Use Cases for Badges

Badges are versatile and can be used in various contexts:

  • Notifications: Show the number of unread messages or alerts.
  • Labels: Highlight special categories like "VIP" or "Featured".
  • Status Indicators: Display the status of tasks or items (e.g., "Active", "Pending").
  • Tags: Categorize content (e.g., "Technology", "Design").

Next Steps
