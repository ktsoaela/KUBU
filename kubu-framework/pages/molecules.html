Molecules of Kubu

Molecules are composed of multiple atoms working together to create functional components. They form the building blocks for more complex structures, ensuring reusability and maintainability within the Kubu design system.

How BEM and Atomic Design Work Together

Molecules in Kubu follow the BEM methodology for structured and modular CSS. A molecule consists of multiple atoms structured using BEM classes to maintain clarity. For example, a breadcrumb (a molecule) combines links (atoms) using .breadcrumb (block), .breadcrumb__item (element), and .breadcrumb--active (modifier).

Molecules Overview

Below is a breakdown of the molecules used in Kubu:

Announcements

Announcement components display important messages such as alerts, warnings, or success notifications. They typically include a title, message, and a close button.

Breadcrumb

Breadcrumbs help users navigate hierarchical structures by providing a clear path back to previous sections. They consist of multiple links (atoms) within a breadcrumb container.

Button Groups

Button groups allow multiple buttons to be grouped together, providing a compact and organized layout for related actions.

Dropdowns

Dropdowns provide a way to display additional options in a compact menu. They typically include a toggle button (atom) and a dropdown menu containing list items.

Form Groups

Form groups organize form elements such as labels, input fields, and validation messages. They ensure consistent spacing and alignment across form sections.

List Groups

List groups provide a way to display a structured list of items, often used for menus, notifications, or selection-based components.

Navbar

The navbar molecule provides a structured layout for navigation menus. It includes branding, links, and optional dropdowns.

Navs

Navs are navigation elements used for switching between different sections within a page or application. They are commonly found in tabbed interfaces.

Pagination

Pagination components help users navigate through large sets of content by breaking it into pages. They consist of page links and navigation controls.
