KUBU 2.0

The whole contract on one page: link one CSS file, compose BEM parts, treat every page as an endpoint, and install a package only when you want a slice.

Kubu is the hippo. It holds the page: one stylesheet, named parts, and a layout that still works when the script is gone.

1. Link one CSS file

dist/kubu.min.css holds every atom, molecule and organism, themed for dark and light. Nothing else is required.

Code 
<link rel="stylesheet" href="/static/kubu.min.css">

Get it from Download, from npm install kubu-css, or from pip install kubu-css for Django and Flask static files.

2. Compose BEM parts

A component is a block with named parts. Use the parts you need; there are no options to configure and no JavaScript to call.

Order 1042

Paid

Two mohair blankets, delivered to Maseru.

View the order
Code 
<article class="card">
    <header class="card__header">
        <h3 class="card__title">Order 1042</h3>
        <span class="badge badge--safe">Paid</span>
    </header>
    <div class="card__body"><p>Two mohair blankets, delivered to Maseru.</p></div>
    <footer class="card__footer"><a class="button button--primary" href="page-product.html">View the order</a></footer>
</article>

Lay the parts out on the grid. Twelve columns is the default: .grid with .col-1 to .col-12. .grid--13 is the extra option, for uneven splits like 5+8; see Grid.

3. Every page is an endpoint

Each address returns a whole HTML page, the same way a backend route does. With htmx, hx-boost on <body> swaps only the region you name and keeps the URL, the title and Back right. Without it, the same link loads the whole page.

Code 
<body hx-boost="true" hx-target="#content" hx-select="#content" hx-swap="outerHTML" hx-push-url="true">

Components never depend on that script. Dialogs, disclosures, popovers, tabs and the theme switch run on <dialog>, <details>, popover, :target, radio buttons and checkboxes.

4. Install a slice only when you want one

Each folder in kubu-framework/packages has one job. None of them is needed for a component to look right.

PackageWhat it holds
packages/webA starter site: three pages, one stylesheet, htmx navigation.
packages/typographyColours, spacing, type and the reset, without any components.
packages/iconsThe icon CSS and the SVG sprite from the Icon Pack.
packages/pluginhtmx patterns: out-of-band toasts and one listener on a parent.
packages/jsOptional ES modules for what HTML cannot do alone. See JavaScript.
