Button Groups

Related actions joined into one control, like the views of a list or the alignment of text.

File: css/molecules/ButtonGroups.css

Actions

Code 
<div class="button-group" role="group" aria-label="Invoice actions">
    <button class="button button--outline" type="button">Edit invoice</button>
    <button class="button button--outline" type="button">Duplicate</button>
    <button class="button button--outline" type="button">Download PDF</button>
</div>

A choice of one

When the group picks one option, make it radio buttons, so it works in a form and with scripts off.

Show orders
Code 
<fieldset class="theme-switch-list">
    <legend class="visually-hidden">Show orders</legend>
    <input type="radio" name="bg-view" id="bg-all" checked><label for="bg-all">All orders</label>
    <input type="radio" name="bg-view" id="bg-open"><label for="bg-open">Open</label>
    <input type="radio" name="bg-view" id="bg-closed"><label for="bg-closed">Closed</label>
</fieldset>

Parts

ClassRole
.button-groupBlock: a row of .buttons with shared edges. Add role="group" and an aria-label.
.buttonEach action, from Buttons.
