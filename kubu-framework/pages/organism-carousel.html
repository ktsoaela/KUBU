Carousel

Slides in a row that snap into place as you swipe, scroll or use the arrow keys. Scroll snap does the work; there is no script.

File: css/organisms/Carousel.css

Example

Sani Pass

Maletsunyane Falls

Thaba Bosiu

Sani Pass Maletsunyane Falls Thaba Bosiu
Code 
<section class="carousel carousel--peek" tabindex="0" aria-label="Featured trips, scroll sideways">
    <article class="carousel-item" id="slide-1" aria-label="1 of 3"><h3>Sani Pass</h3></article>
    <article class="carousel-item" id="slide-2" aria-label="2 of 3"><h3>Maletsunyane Falls</h3></article>
    <article class="carousel-item" id="slide-3" aria-label="3 of 3"><h3>Thaba Bosiu</h3></article>
</section>
<nav class="nav nav--pills" aria-label="Slides">
    <a class="nav__link" href="#slide-1">Sani Pass</a>
    <a class="nav__link" href="#slide-2">Maletsunyane Falls</a>
    <a class="nav__link" href="#slide-3">Thaba Bosiu</a>
</nav>

The links under the slides jump to each one by its id, so every slide can be reached without swiping.

Parts

ClassRole
.carouselBlock: the scroll container. Give it tabindex="0" and an aria-label so it can be scrolled with keys.
.carousel--peekModifier: slides take 85% so the next one shows.
.carousel-itemElement: one slide, snapped to the centre.

Guidance

  • Do not auto-advance. If you must, the KUBU 2.0 Carousel can, and it pauses on hover and focus.
  • Put the most important slide first: many people never scroll.
