Breadcrumb

Shows where the current page sits in the site, with a link to each level above it.

File: css/molecules/Breadcrumb.css

Example

  1. Home
  2. Papers
  3. Breadcrumb
  1. Shop
  2. Lamps
  3. Desk lamp
Code 
<nav aria-label="Breadcrumb">
    <ol class="breadcrumb">
        <li class="breadcrumb__item"><a class="breadcrumb__link" href="index.html">Home</a></li>
        <li class="breadcrumb__item"><a class="breadcrumb__link" href="papers.html">Papers</a></li>
        <li class="breadcrumb__item breadcrumb__item--active" aria-current="page">Breadcrumb</li>
    </ol>
</nav>
<nav aria-label="Breadcrumb, arrow style">
    <ol class="breadcrumb breadcrumb--arrow">
        <li class="breadcrumb__item"><a class="breadcrumb__link" href="showcases.html">Shop</a></li>
        <li class="breadcrumb__item"><a class="breadcrumb__link" href="page-product.html">Lamps</a></li>
        <li class="breadcrumb__item breadcrumb__item--active" aria-current="page">Desk lamp</li>
    </ol>
</nav>

Parts

ClassRole
nav[aria-label="Breadcrumb"] > ol.breadcrumbBlock: the ordered trail inside a labelled landmark.
.breadcrumb__itemElement: one level. The separator is drawn in CSS.
.breadcrumb__linkElement: the link, 44px tall.
.breadcrumb__item--activeModifier: the current page, with aria-current="page".
.breadcrumb--slash, --dot, --arrowModifier: separator style.

A server-side fragment lives in templates/breadcrumb-template.html.
