Notifications

An inline status message for one region, like the result of a save. Each tone has an icon and a sentence.

File: css/utilities/Notifications.css, with the icons in css/organisms/Alerts.css

Tones

Settings saved. They apply from your next sign-in.
Two people are editing this page.
This link expires in 24 hours.
The file is too large. Choose one under 5 MB.
Code 
<div class="notification success" role="status">Settings saved. They apply from your next sign-in.</div>
<div class="notification info" role="status">Two people are editing this page.</div>
<div class="notification warning" role="status">This link expires in 24 hours.</div>
<div class="notification error" role="alert">The file is too large. Choose one under 5 MB.</div>

Parts

ClassRole
.notificationBlock: the tinted box with an icon.
.success, .info, .warning, .errorTone and icon.
.closeAn optional dismiss control, with aria-label.

For a message that applies to the whole page, use an Alert. For a passing confirmation, a Toast.
