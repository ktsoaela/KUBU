Forms

Forgiving forms: errors wait until you leave a field, say how to fix it, and the send button wakes up when everything required is valid.

File: css/organisms/Forms.css, with css/molecules/FormGroups.css

Forgiving validation

Type an incomplete email, then move to the next field. The error appears only after you leave it (:user-invalid). The button stays dimmed until both required fields are valid (:has(:invalid)).

Enter an email address with an @ and a dot, like palesa@example.com.

Use at least 12 characters. A short sentence is easy to remember.

Code 
<form class="form-container form-container--guarded" action="organism-forms.html" method="get">
    <div class="form-group">
        <label class="form-label" for="fm-email">Email <span class="form-label__hint">(required)</span></label>
        <input class="form-input" id="fm-email" name="email" type="email" autocomplete="email" required pattern=".+@.+\..+" placeholder="e.g. palesa@example.com" aria-describedby="fm-email-error">
        <p class="form-error form-error--live" id="fm-email-error">Enter an email address with an @ and a dot, like palesa@example.com.</p>
    </div>
    <div class="form-group">
        <label class="form-label" for="fm-password">Password <span class="form-label__hint">(required, 12 characters or more)</span></label>
        <input class="form-input" id="fm-password" name="password" type="password" autocomplete="new-password" required minlength="12" aria-describedby="fm-password-error">
        <p class="form-error form-error--live" id="fm-password-error">Use at least 12 characters. A short sentence is easy to remember.</p>
    </div>
    <button class="form-submit" type="submit">Create account</button>
</form>

An error from the server

When the server rejects a value, render the field with aria-invalid="true" and the error text, linked with aria-describedby.

thabo is taken. Try thabo.m or add a number.

Code 
<div class="form-group">
    <label class="form-label" for="fm-user">Username <span class="form-label__hint">(required)</span></label>
    <input class="form-input" id="fm-user" name="username" type="text" value="thabo" aria-invalid="true" aria-describedby="fm-user-error">
    <p class="form-error" id="fm-user-error">thabo is taken. Try thabo.m or add a number.</p>
</div>

Stay on the page with htmx

The form posts to its own URL without htmx. With htmx, the reply replaces only the result area under the form. The button shows its loading state as soon as you send.

Code 
<form class="form-container" action="organism-forms.html" method="get" hx-get="../templates/subscribe-response.html" hx-target="#fm-result" hx-select="unset" hx-swap="innerHTML" hx-push-url="false" hx-indicator="#fm-subscribe" hx-disabled-elt="#fm-subscribe">
    <div class="form-group">
        <label class="form-label" for="fm-news">Email for release notes</label>
        <input class="form-input" id="fm-news" name="email" type="email" autocomplete="email" required>
    </div>
    <button class="button button--primary" id="fm-subscribe" type="submit">Get release notes <span class="spinner spinner--small htmx-indicator" aria-hidden="true"></span></button>
    <div id="fm-result" aria-live="polite"></div>
</form>

Toggle

A toggle is a checkbox with role="switch". It posts like any checkbox, so it needs no script. The knob moves to the right when it is on, and the label says what turns on.

Code 
<form action="organism-forms.html" method="get">
    <label><input class="toggle" type="checkbox" role="switch" name="notify" checked> Email me when the order ships</label>
    <label><input class="toggle" type="checkbox" role="switch" name="sms"> Send me a text on delivery day</label>
</form>

One-time code

Use one field, not six boxes. Six boxes that move focus need a script. One field with autocomplete="one-time-code" lets the phone offer the code from the message, and a paste fills it all at once.

Six digits. It works for ten minutes.

Code 
<form class="form-group" action="organism-forms.html" method="get">
    <label class="form-label" for="otp-code">Code from the text message</label>
    <input class="form-input form-input--otp" id="otp-code" name="code" type="text" inputmode="numeric" autocomplete="one-time-code" pattern="[0-9]{6}" maxlength="6" required aria-describedby="otp-hint">
    <p><small id="otp-hint">Six digits. It works for ten minutes.</small></p>
</form>

Parts

ClassRole
.form-containerBlock: a centred column, at most 400px wide.
.form-container--guardedModifier: dims the submit button until every required field is valid.
.form-group, .form-label, .form-inputThe field parts, from FormGroups.
.form-errorElement: icon, danger colour and a sentence that names the fix.
.form-error--liveModifier: hidden until the field is :user-invalid.
.form-submitElement: a full-width, 48px send button.
.toggleBlock: a checkbox drawn as an on and off track, with the one radius. Add role="switch".
.form-input--otpModifier: a one-time code field, monospaced and spaced out. One field, not six.

Rules

  • Never show an error before someone has had a chance to type.
  • Error text says what to do: "Enter all 8 digits", not "Invalid input".
  • Keep the browser's validation on; it is the fallback when CSS cannot help.
