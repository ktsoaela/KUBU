Component menu

Dropdowns

A short menu that opens from a labelled button. It opens and closes with HTML alone.

File: css/molecules/Dropdowns.css

With <details> (recommended)

Click or press Enter on the summary to open; again to close. It works the same on touch.

Account menu
  • Profile
  • Settings
  • Sign out
Export
  • As CSS
  • More formats
Code 
<details class="dropdown">
    <summary class="button button--primary">Account menu</summary>
    <ul class="dropdown-content">
        <li><a class="dropdown-item" href="page-about.html">Profile</a></li>
        <li><a class="dropdown-item" href="organism-forms.html">Settings</a></li>
        <li><a class="dropdown-item" href="index.html">Sign out</a></li>
    </ul>
</details>
<details class="dropdown dropdown--end">
    <summary class="button button--outline">Export</summary>
    <ul class="dropdown-content">
        <li><a class="dropdown-item" href="../dist/kubu.css" hx-boost="false">As CSS</a></li>
        <li><a class="dropdown-item" href="download.html">More formats</a></li>
    </ul>
</details>

With :focus-within

For a menu inside a navbar list. It opens while focus is inside it, and closes when focus leaves.

    • Getting started
    • Theming
Code 
<ul class="dropdown">
    <li class="dropdown-item-container">
        <button class="button button--outline" type="button">Help topics</button>
        <ul class="dropdown-content">
            <li><a class="dropdown-item" href="start-intro.html">Getting started</a></li>
            <li><a class="dropdown-item" href="start-theming.html">Theming</a></li>
        </ul>
    </li>
</ul>

Parts

ClassRole
details.dropdown or ul.dropdownBlock: positions the menu.
summary with .buttonThe labelled trigger. A down arrow is added in CSS.
.dropdown-contentElement: the menu panel.
.dropdown-itemElement: one link, 44px tall.
.dropdown-item-containerElement: the li that opens on :focus-within.
.dropdown--endModifier: align the menu to the right edge.

Accessibility

  • Label the trigger with what the menu holds: "Account menu", not an icon.
  • Use links for places and buttons for actions inside the menu.
