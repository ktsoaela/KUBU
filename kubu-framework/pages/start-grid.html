Grid

A 12-column CSS grid for page layout, a 13-column option for uneven splits, and an auto-fit grid for lists of cards. The grid is where a part sits. Left, right, and the middle of a row are column spans. Half the row is .col-6. The whole row is .col-12. A card or a button does not take a width or a height of its own.

File: css/utilities/Grid.css

Twelve columns

Children of .grid span all twelve columns until you give them a .col-* class. Prefix a class with sm:, md: or lg: to apply it from 640, 768 or 1024 pixels up.

Article: col-12 md:col-8
Aside: col-12 md:col-4
col-6 lg:col-3
col-6 lg:col-3
col-6 lg:col-3
col-6 lg:col-3
Code 
<div class="grid">
    <div class="col-12 md:col-8 demo_product">Article: <code>col-12 md:col-8</code></div>
    <div class="col-12 md:col-4 demo_product">Aside: <code>col-12 md:col-4</code></div>
    <div class="col-6 lg:col-3 demo_product"><code>col-6 lg:col-3</code></div>
    <div class="col-6 lg:col-3 demo_product"><code>col-6 lg:col-3</code></div>
    <div class="col-6 lg:col-3 demo_product"><code>col-6 lg:col-3</code></div>
    <div class="col-6 lg:col-3 demo_product"><code>col-6 lg:col-3</code></div>
</div>

Thirteen columns

Twelve columns is the default, and every page should start there. .grid--13 is the extra option, for the splits twelve cannot make: a 5+8 or 6+7 layout is off-centre on purpose. Children span the whole row until you give them a span, so on a phone each part is full width. The spans inside .grid--13, including .col-13 for a full row, apply only there.

As many as fit

.grid--auto makes columns at least 16rem wide and fits as many as the space allows. No breakpoints to choose.

    <li class="card"><h3 class="card__title">Plan</h3><p class="card__body">Write the outline.</p></li>
    <li class="card"><h3 class="card__title">Build</h3><p class="card__body">Turn it into HTML.</p></li>

</ul>

Parts

ClassWhat it does
.containerCentres the content, at most 1200px wide, with fluid side padding.
.gridTwelve equal columns with a --grid-gap gap (default --space-md).
.col-1 … .col-12Span that many columns at every width.
.sm:col-*, .md:col-*, .lg:col-*Span from 640px, 768px or 1024px up.
.grid--13The extra option: thirteen columns. Twelve is the default.
.grid--13 > .col-1 … .col-13, md:, lg:Spans out of thirteen. They apply only inside .grid--13.
.grid--autoAs many 16rem-or-wider columns as fit.
.cqMakes the element a size container for @container queries.
